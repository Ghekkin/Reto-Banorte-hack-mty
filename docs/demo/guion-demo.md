# Guion de la demo (plan; se reescribe cuando se elija el caso de uso)

Objetivo: **3 minutos**, sin pausas, mostrando al menos **tres interfaces distintas**
generadas por el agente en una misma conversación, y una que el agente componga de
dos resultados.

## Estructura

| Min | Qué pasa en pantalla | Qué se dice |
|---|---|---|
| 0:00–0:20 | Pantalla vacía, solo el chat | El problema en una frase. Quién es el usuario. |
| 0:20–1:00 | Pregunta 1 → el agente genera UI tipo A (ej. gráfica) | "No programamos esta pantalla: el agente decidió mostrarla" |
| 1:00–1:40 | Pregunta 2 → UI tipo B (ej. tabla filtrable) | Cómo el MCP expone los datos |
| 1:40–2:20 | Pregunta 3 → UI tipo C (ej. formulario con acción) | El agente actúa, no solo muestra |
| 2:20–2:50 | Pregunta que combina → UI compuesta | El cierre: "cada usuario ve la interfaz que necesita" |
| 2:50–3:00 | Qué sigue | Una frase |
