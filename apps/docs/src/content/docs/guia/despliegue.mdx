## Endpoints Públicos de Producción

Los evaluadores pueden inspeccionar el sistema en vivo en los siguientes dominios:

* **Aplicación Web Maya:** `https://ghekkinxmaya.tech`
* **Catálogo A2UI JSON:** `https://ghekkinxmaya.tech/catalogo/v1.json`
* **Healthcheck del Servidor MCP:** `https://mcp.ghekkinxmaya.tech/health`
* **Documentación Técnica Astro:** `https://docs.ghekkinxmaya.tech` (en local: `pnpm docs:dev`, puerto 4321)

---

## Contenedores Docker

La raíz del monorepo contiene los archivos Docker optimizados:

* `apps/web/Dockerfile`: Compilación multi-stage de Next.js 16 con standalone output y assets estáticos.
* `apps/mcp/Dockerfile`: Imagen ligera Node.js con compilación TypeScript para el servidor MCP.
* `apps/docs/`: Despliegue estático de Astro con salida HTML pre-renderizada de alto rendimiento y búsqueda por Pagefind.
