## Principios de Diseño de Componentes

Cada componente del catálogo respeta los principios acordados en el sistema de diseño:

1. **Una sola idea por tarjeta:** Cada widget se enfoca en resolver un concepto claro (un saldo, una comparativa de plazos o un gráfico de categorías).
2. **El monto como elemento más grande:** Los importes monetarios utilizan la clase `tabular-nums` y fuentes de tamaño prominente para máxima legibilidad.
3. **Objetivos táctiles de 48 px:** Todos los botones, interruptores y sliders están optimizados para dedos en dispositivos móviles.
4. **Semántica de colores Banorte:** El rojo (#EC0029) se reserva exclusivamente para la acción primaria o llamadas de atención por morosidad o fugas críticas.
